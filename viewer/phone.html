门口收纳盒 · 3D 预览

7 款外观对比，支持手机旋转查看。

先看图片（推荐） 打开 3D 预览

手机上怎么看？

  1. 电脑在项目目录运行：
    bash scripts/serve_preview.sh
  2. 手机和电脑连同一个 WiFi
  3. 手机浏览器打开终端里显示的地址
    （形如 http://192.168.x.x:8766/viewer/entryway.html）
没有电脑在身边？
合并 PR 后开启 GitHub Pages，手机打开：
https://ll3239.github.io/lenticular-test/viewer/entryway.html

或下载 output/styles/*.stl，用 STL 查看 App 打开。
